[![Download Latest](https://img.shields.io/github/v/release/MetropolisRoadKnot98/buildcraft-automation-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/MetropolisRoadKnot98/buildcraft-automation-mod/releases/latest)

The original Minecraft automation mod with pipes, builders, quarries, and the Minecraft Joules energy system.

![BuildCraft — Pipe Automation Mod Preview](https://cdn.modrinth.com/data/6X5wjPTJ/images/5eae4994ec87be795c20698ffdbe70b6ada17329_350.webp)

## Features

- Quarry multiblock for automated strip mining
- Item, fluid, and power pipe network system
- Builder and Filler for automated construction
- Gates and wire logic for programmable pipe sorting
- Robotics update adds programmable robot workers

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
